# Phase 13: Enhanced Symbol Data Matrix & Context-Aware Integrity Engine

## Objective
Upgrade the bare symbol table into an actionable Symbol Coverage Matrix and enhance the Data Integrity Engine with symbol-specific targeting and recorded-date discovery.

## Tasks
- [ ] Task 1: Build the rich Symbol Coverage Matrix table in `index.html` displaying display name, asset class, stored bar count, recorded date range (start → end), latest close price, freshness status, and data sources list.
- [ ] Task 2: Implement search filtering and quick action buttons ("Chart", "Audit", "Remove").
- [ ] Task 3: Upgrade Data Integrity UI with target symbol selector, automated discovery of symbol max recorded dates, and detailed gap/anomaly/drift breakdown.
