# Phase 11: Interactive Financial Charting & Data Explorer UI

## Objective
Embed high-performance interactive financial candlestick and volume charting into `src/dashboard/static/index.html` using TradingView Lightweight Charts, coupled with a raw candle inspector table and CSV data exporter.

## Tasks
- [ ] Task 1: Include TradingView Lightweight Charts standalone bundle in HTML head.
- [ ] Task 2: Build the Chart Explorer UI layout:
  - Header toolbar with Symbol picker, Timeframe pills (1m, 5m, 15m, 30m, 1h, 4h, 1D), Candle count selector, and Refresh button.
  - Responsive canvas container with dark-mode styling and hover OHLCV legend.
  - Candlestick series + linked Volume histogram series.
- [ ] Task 3: Build the Raw Candle Inspector Table:
  - Interactive table showing Time, Open, High, Low, Close, Volume, Source, and Session.
  - Search filter and pagination.
  - "Export CSV" functionality.
- [ ] Task 4: Connect JavaScript client to `GET /api/candles` with responsive chart updates and loading indicators.
- [ ] Task 5: Verify chart rendering, timeframe switching, symbol swapping, and CSV export.
