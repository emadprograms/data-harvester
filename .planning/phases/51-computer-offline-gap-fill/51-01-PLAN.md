# Phase 51 Plan 01: Computer-offline gap fill

**Goal:** Naming one day requests only the stretches where every active symbol is silent, and writes the returned bid and ask.

**Requirements:** QFILL-01, QFILL-02, QFILL-03, QFILL-04, QFILL-05

## Locked decisions

- This phase does not rewrite existing files. The lake rewrite stays in Phase 53.
- A hole is all active registry symbols silent together. One symbol ticking means that minute is not a hole.
- The request window is 04:00–20:00 ET. Pre-market and post-market need 15 minutes. Regular hours need 2 minutes.
- A stretch that crosses 09:30 or 16:00 is split before the threshold is applied. The two pieces are separate requests.
- Weekends and full NYSE holidays produce no request. The holiday list must match the NYSE Group 2024–2026 calendar, including Good Friday.
- An official early close is 13:00 ET. Time after that close is not requested, including the late session. The day before the close is still eligible.
- Databento is asked with schema `tbbo` and only for the qualifying stretches. Returned `bid_px_00` and `ask_px_00` are stored as `bid_price` and `ask_price`. A smaller row count is not a second request.
- The command checks the publisher lock before any Databento call. If the live writer holds it, the command refuses.

3. Add a one-day command that scans the fixture lake, requests only those stretches, and publishes schema v2.
