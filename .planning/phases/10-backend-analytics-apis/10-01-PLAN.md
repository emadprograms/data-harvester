# Phase 10: Backend Analytics & High-Performance Data APIs

## Objective
Implement high-performance DuckDB analytical REST endpoints in `src/dashboard/server.py` supporting candle extraction with time-bucketing, symbol coverage and health summaries, live stream tape and process telemetry, market session calculations, and background harvester execution with log streaming.

## Tasks
- [ ] Task 1: Implement candle fetching endpoint `GET /api/candles` with DuckDB `time_bucket()` aggregation (1m, 5m, 15m, 30m, 1h, 4h, 1d) and chronological sorting.
- [ ] Task 2: Implement symbol coverage & health endpoint `GET /api/symbols/coverage` providing bar counts, timestamp bounds, latest close, source breakdowns, and freshness tags.
- [ ] Task 3: Implement streaming tape `GET /api/stream/tape` and process status `GET /api/stream/status` with liveness checks and tick rate calculations.
- [ ] Task 4: Implement market session status endpoint `GET /api/market/session` with US Eastern session phase and countdown calculations.
- [ ] Task 5: Implement harvester background trigger `POST /api/harvester/run` and status/log monitor `GET /api/harvester/status`.
- [ ] Task 6: Add automated tests for all endpoints in `tests/test_dashboard_v3.py`.
