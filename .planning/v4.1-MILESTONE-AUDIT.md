## 5. Audit Remediation Details (Commit `e6763f9f`)

### INT-1: Resolved Staging Cleaner API Shadowing
- **Issue:** `cleanup_orphaned_staging_files` in `src/storage/registry.py` shadowed `src/storage/publication.py` at the package root `src/storage/__init__.py`.
- **Resolution:** Defined `cleanup_orphaned_registry_staging_files` in `src/storage/registry.py` (with a backward-compatibility alias). Updated `src/storage/__init__.py` to export `cleanup_orphaned_staging_files` (from `publication.py`, also aliased as `cleanup_orphaned_parquet_staging_files`) and `cleanup_orphaned_registry_staging_files` (from `registry.py`) in `__all__`.

### INT-2: Eliminated Test-Aware Production Hooks
- **Issue:** `src/dashboard/analytics.py` contained `_is_mocked_db_connection` importing `unittest.mock` to inspect connections.
- **Resolution:** Completely removed `_is_mocked_db_connection` and all `unittest.mock` imports from `src/dashboard/analytics.py`. Replaced with clean query routing: when `client is None`, `_get_lake_reader()` is checked; when caller provides an explicit `client`, it executes directly against DuckDB.

### INT-3: Surfaced Drop Telemetry & Rate-Limited Overload Disk I/O
- **Issue:** Drop telemetry (`total_dropped`, `queue_depth`) was stored in `writer_status.json` but not surfaced via reader/dashboard APIs. Furthermore, `write_tick()` wrote to disk on every single dropped tick.
- **Resolution:**
  - Added `_drop_status_write_interval_seconds = 1.0` in `TickLakeWriter` to throttle status file writes during queue saturation.
  - Updated `TickLakeReader.get_stream_status()` to return `total_dropped` and `queue_depth`.
  - Updated `src/dashboard/analytics.py:get_stream_status()` and `src/utils/integrity.py` to parse and expose `total_dropped` and `queue_depth`.

### TEST-P23-02: Real OS Signal & Subprocess Runner Test
- **Issue:** `test_runner_sigint_sigterm_lifecycle` previously invoked `engine.stop()` directly without testing OS signal handlers.
- **Resolution:** Added CLI flags to `src/stream/runner.py` (`--mock`, `--flush-interval`, `--lake-root`, `--drain-delay`, `--ticks-per-sec`) backed by an in-process synthetic `MockStreamer`. Refactored `test_runner_sigint_sigterm_lifecycle` to spawn a real OS subprocess running `python -m src.stream.runner --mock`, send real OS `SIGINT` and `SIGTERM`, and verify exit code 0, STOPPED status, and Parquet data integrity.

### TEST-P27-02 / FLOW-4: Real Streamer Process Chaos Monkey
- **Issue:** Chaos monkey tests ran against `tools/synthetic_streamer.py` rather than `src.stream.runner`.
- **Resolution:** Updated `tests/integration/test_supervisor_chaos_soak.py` to execute chaos operations (`kill -9`, rapid flapping with `--fail-immediately`, SIGTERM graceful drain with `--drain-delay`) directly against `src.stream.runner` subprocesses managed by `ProcessSupervisor`.
